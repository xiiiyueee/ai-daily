Peter 从 Dario 和 Daniela 的最新访谈里提炼出几条核心观点。Dario 透露 Anthropic 今年早些时候看到「使用量和收入 80 倍增长」，并直言「我们会尽可能多地获取算力」。Daniela 给创始人的建议是「为指数增长而构建」——有些产品用当前模型做不出来，但随着模型进化会跑起来，这对内部实验提出了更高要求：「你必须真的用模型试一下才知道可不可行。」

两人还抛出一个有意思的观察：「产品在模型变得太好时反而会触碰天花板。今天让模型变聪明的方式，在 agentic 和 Claude Code 工作流里的体现远比 chatbot 明显。」另一个值得玩味的点：「模型正在从写代码进化到做软件工程，再进化到直接经营一门生意。」

这三点合起来描绘了一种 Anthropic 内部已经到达、但外界还完全没进入的工作方式：不是坐在电脑前和 agent 打字，而是像编排一支隐形团队那样管理数百乃至数千个并行任务。

Claude 官方 （Anthropic）

Claude 在 Code with Claude 大会上一口气放出两个新能力。一是 Outcomes：「你写一份 rubric，一个独立的 grader 检查输出，agent 会自己迭代直到达标」，还支持 webhook 通知——本质是把质量标准从"人工检查"变成"规则自动判分 + 自动重试"。

二是 Dreaming：「复盘 agent 过去的会话，提取模式，整理成记忆」，让 agent 真的能越用越懂你。两个功能都指向同一件事：把 agent 从"一次性执行者"升级成"持续学习 + 自我优化"的长期工作者。

Training Data：「Anthropic Boris Cherny：编程的印刷机时刻」
关键观点：Claude Code 之父 Boris 判断编程对他而言「已经被解决了」——模型写他 100% 的代码，一天能推 150 个 PR。更激进的预测是：编程会像读写能力一样被完全民主化，且「比五十年快得多」。

Boris 分享了一个让全场震惊的工作流：他现在主要在手机上写代码。「Claude app 左边有个 code tab，我通常挂着 5 到 10 个 session，每个 session 下面跑一堆 agent，当前大概有几百个 agent 在跑，晚上会有几千个做更深的活。」

他最爱用的功能是 /loop——让 Claude 用 cron 调度一个重复任务，「我现在有几十个 loop 在跑：一个帮我盯 PR、修 CI、自动 rebase；一个保持 CI 健康、自动修 flaky 测试；还有一个每 30 分钟从 Twitter 抓反馈并聚类给我。」这已经不是"用 AI 写代码"，而是"指挥一支隐形团队持续产出"。

关于 SaaSpocalypse，Boris 的判断很冷静。他引用 Hamilton Helmer 的《7 Powers》框架，认为有些护城河会被 AI 削弱——比如 switching cost（模型可以帮你一键搬家）和 process power：「4.7 对任何目标都能做爬山优化，给它一个 target 它会一直迭代到完成。」但 network effects、scale economies、cornered resources 这些老护城河基本不受影响。真正的结论是：「未来十年会多出 10 倍数量的颠覆性创业公司，因为一家小团队能建出跟大公司同等价值的产品，而大公司被内部流程和变革阻力拖住。」

最有历史感的类比是关于印刷机。「1400 年代印刷机发明前，欧洲只有 10% 的人识字。印刷机出现后 50 年里，欧洲出版的书籍量超过前一千年总和，书的成本降了 100 倍。又过了几百年，全球识字率升到 70%。」他的预测是：「软件会被完全民主化——而且比 50 年快得多。」一个推论让人耳目一新：最适合写财务软件的人不是工程师，而是一个真正懂业务的会计，因为「领域知识才是难的部分，写代码反而是容易的」。

Boris 还抛出一个组织层面的观察：Anthropic 内部所有代码都由模型写，所有 SQL 都是模型生成的，「我的 Claude 之间会通过 Slack 互相对话，跟其他人的 Claude 协作解决未知问题」。他认为 Anthropic 领先外界的不是技术——模型大家都能用——而是「组织结构和流程的重构」，这才是同行真正要追赶的部分。
